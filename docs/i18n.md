# BackOffice 语言规则

一条规则：用户看到的文字只有一种语言，就是页面的语言。

| 文字来源 | 怎么做 | 谁检查 |
| --- | --- | --- |
| 当前语言 | 只看地址栏第一段（`useLocale()`，非 React 代码用 `currentLocale()`） | |
| 界面文案 | `t()` 语言包，课程模块用成对的 `L(locale, 中文, 英文)` | `client/tests/i18n-guard.test.ts` |
| 后端错误句子 | 请求层一律过 `serverText()`：同语言原样显示，有译文显示译文，否则显示通用提示 | 同上，会扫描 `server/src` 里的中文报错 |
| 日期时间 | `formatDateTime(locale, value)`，不用不传语言的 `toLocaleString()` | 同上 |
| 课程、人名等数据 | 按数据原样显示，不算界面文案 | |

新增文案或后端报错时，上面的守卫测试会提醒缺什么。浏览器里的整页检查在
`client/e2e/i18n-language.e2e.test.mjs`（`npm run test:e2e:i18n`）：它把浏览器语言设成相反的语言，
逐页读取渲染结果，任何来源的另一种语言都会失败。

中文里允许的英文（产品固定用词、文件格式等）列在守卫测试的 `ZH_ALLOWED_TERMS`。
