# 课程管理 UIUX 重构设计（RWD / 固定外壳 + 内滚动分区）

> 2026-11-20 · 依据：UIUX 原型（Claude Artifact `2jphsxy3CapbrdKaN8wtpy` 三屏）、`backoffice.css` 既有模板、术语调研 `verify-takeover-20261116/frontend-proportion-terminology.md`。
> 目标：课程页回归项目既有惯例——**固定外壳、流式断点、面板内部滚动、抽屉编辑**；不再纵向堆叠成长页。

## 1. 原则

1. 术语与模式：**Responsive Web Design + Fluid Grid**（不是等比缩放，不做整页 scale）。
2. 外壳：`.shell` 100vh、顶栏 68、侧栏 280/240/220/折叠；`.content` flex:1，页面本体**不滚动**。
3. 页面 = 固定头部 + 页签/工具栏 + **面板区**；长内容放进面板内部滚动或抽屉。
4. 分栏用 `minmax(0, 1fr)`，断点 1400 / 1100 / 900 与壳层一致；<1100 纵向折叠。
5. 状态信息只出现一次（头部摘要），不在卡片、步骤条重复。
6. 视觉与 Figma 1672×941 对齐；e2e 视口锁定 1672×941。

## 4. 布局 token 与断点

| 项 | 规则 |
|---|---|
| 内容区 | `.content` flex:1；卡片 `card cardGrow` 撑满；**页面不滚动** |
| 分栏 | `grid-template-columns: minmax(0, 40%) minmax(0, 1fr)` 等，禁止裸 `fr` 溢出 |
| 内部滚动 | 每个面板 `overflow:auto; min-height:0`；表格 `tableWrap` 既有模式 |
| ≥1400 | 设计稿布局；侧栏 280 |
| 1100–1400 | 侧栏 240；分栏 38/62；表格列可收窄 |
| <1100 | 双栏纵向折叠为单列（各自内部滚动）；页签吸顶 |
| <900 | 侧栏折叠；面板全宽；表格最大高度 60vh（沿用壳层规则） |
| 高 <700 | 压缩留白（沿用壳层规则） |

## 5. 现状实现问题（代码审计，非截图问题）

1. `CourseEditorPage.tsx:169` 整卡片 `overflow: 'auto'` → 整页随内容变长，而不是面板内部滚动。
2. 头部 DRAFT/LIVE 双卡（:193-207）+ 页签步骤（:209-236）重复表达状态与完成度。
3. 各页签内容纵向堆叠卡片（Info 4 张卡、Content 课时卡越叠越长、Versions Current+Versions+History 顺序堆叠）。
4. 课程页未接壳层断点；部分硬编码列宽（如 `280px 1.2fr 1fr`）在窄屏不折叠。
5. 长表单/导入未统一收进抽屉（部分用 Modal/内联），与既有模式不一致。

## 6. 验收（实现完成后）

- 1672×941 截图：每个页签一屏内可见，长内容只在面板内滚动（document 不滚动）。
- e2e 断言：`document.scrollingElement.scrollHeight <= innerHeight + 1`；面板 `scrollHeight > clientHeight` 时可滚；<1100 折叠后无横向溢出。
- 保持既有像素对齐与 e2e 快照；不改服务端契约与课程业务语义。

## 7. 实施顺序

1. 布局骨架：编辑器固定头 + 摘要行 + 吸顶页签 + 面板区（不滚动整页）。
2. Info / Content / Trial / Versions 依次改为分栏 + 内滚动；Versions 改为 Current/Versions/History 分段。
3. 课程列表页对齐设计稿（工具栏/列/分页）。
4. 断点与折叠；截图与 e2e 断言。
