## 1. 变更摘要

本次为 `dev → sit` 增量同步，重点修复 BackOffice 会话有效期、SPA 缓存与登录安全相关问题。

- **会话**：登录会话有效期由 12 小时 / 30 分钟调整为 7 天。
- **缓存**：`index.html` 改为不可缓存，避免部署后浏览器继续加载旧版 SPA。
- **登录安全**：403 或标签页重新获焦时刷新会话；签到、一次性链接、员工管理动作加固。
- **输入校验**：拒绝格式错误的员工邮箱。
- **服务端安全**：隐藏 `X-Powered-By`，统一 JSON 解析错误响应，开放学员 API 时输出告警。

## 2. 变更清单

### 修复 (Fixed)

1. **会话有效期调整为 7 天**
   - 空闲超时与绝对超时统一为 7 天（`SESSION_MAX_DAYS = 7`）。
   - 除非主动签出或清理 Cookie，7 天内无需重新登录。
   - 涉及文件：`server/src/backoffice/lib/securityPolicy.ts`。

2. **SPA 缓存修复**
   - `index.html` 设为不可缓存，部署后强刷即可获取新版本。
   - 涉及提交：`a908079 fix(admin): make index.html non-cacheable to avoid stale SPA after deploy`。

3. **登录与会话加固**
   - 403 或标签页重新获焦时刷新会话。
   - 签到、一次性链接、员工管理动作加固，表单展示前先检查链接状态。
   - 涉及提交：`36568a0`、`717655a`。

4. **员工邮箱校验**
   - 拒绝格式错误的员工邮箱地址。
   - 涉及提交：`fd22270`。

5. **服务端安全响应**
   - 隐藏 `X-Powered-By`，统一 JSON 解析错误响应，开放学员 API 时输出告警。
   - 涉及提交：`20c808c`。

## 3. 测试重点

1. 登录后确认会话在 7 天内有效；主动登出或停用账号后会话立即失效。
2. 部署新版本后强刷页面，确认加载的是最新 SPA，不再出现旧缓存页面。
3. 登录态失效（403）或切换回标签页时，确认会话按预期刷新或回到登录页。
4. 创建/编辑员工时输入格式错误的邮箱，确认被拒绝并给出提示。
5. 激活、重置密码、重发一次性链接，确认旧链接按单次使用与过期规则处理。
6. 回归首版测试矩阵中的登录、员工管理、角色权限与中英文切换。

## 5. 影响范围

- **会话**：有效期延长至 7 天；停用账号、改密等既有吊销逻辑不变。
- **前端缓存**：部署后浏览器不再复用旧 `index.html`，静态资源仍按构建产物缓存策略执行。
- **员工管理**：邮箱格式校验更严格，非法邮箱会在提交前被拒绝。
- **接口**：响应头与错误响应格式微调；不影响 Portal 学员端既有请求/响应契约。

## 6. 已知问题与限制

| 级别 | 类型 | 问题 | 影响与处理 |
|---|---|---|---|
| 低 | 限制 | 会话有效期延长至 7 天 | 共享终端需依赖主动登出或清理 Cookie；SIT 验证按新口径执行 |
| 低 | 限制 | 登录限流仍为单实例内存实现 | 多实例下限流不准确；SIT 单实例不受影响 |
| 低 | 限制 | 无 CSRF token，依赖 SameSite=Lax | 跨站写请求受 Cookie 策略阻断；后续如需强防护再补 |
| 信息 | 范围 | AI Tutor、Knowledge、RAG 等模块同步进入 SIT | 不在本文展开，按各自说明测试 |
