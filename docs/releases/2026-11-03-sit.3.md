## 1. 变更摘要

本次为 `dev → sit` 大版本同步，SIT 首次拿到课程、学生与 HelpDesk 三个完整模块。

- **课程（Commerce Courses，新）**：课程列表/编辑器、课时与展品、文本与视频内容、试看截止点、价格与 Stripe 同步、草稿/发布/版本/恢复、运营位（热门课程、发现横幅）、导出导入、媒体存储与分块上传、学员预览。
- **学生（Student Management，新）**：学生列表与详情抽屉、订阅与特殊状态筛选；Settings 下新增「Learning Access & Experiments」。
- **HelpDesk（新版本）**：工单看板与时间线、双语 FAQ 卡、问题树与发布、候选卡审核（AI 建议、员工确认）、变更日志、数据飞轮看板、Trace 抽屉、评测门与 PII 清洗。
- **AI Tutor**：接地说回答管线（grounded pipeline）、断线续聊、撤销、引用脚注、与 Portal 一致的渲染层。
- **Knowledge**：受管图片资产与编辑器 Widget、图片安全检查。
- **平台与运维**：引擎拆分（admin/agent/ks）、跨实例共享的登录/邮件限流、构建版本自动刷新、Problem+JSON 错误响应、CI 增加客户端测试、HelpDesk PostgreSQL 规范与免费的评测门。
- **课程价格计费周期**：由「每月 / 每年」改为 `1 / 3 / 6 / 12` 个月，并校验 Stripe lookup key 唯一，修复多套餐同步失败。

## 2. 变更清单

### 2.1 新增 (Added)

#### 2.1.1 课程模块（Commerce Courses）

1. **课程列表与总览**：版本/状态列、行操作菜单、统一分页（员工与课程一致）、可调整列宽并记忆。
2. **课程编辑器**：课程信息、学习语言（要求中英双语配置）、What you'll learn / Provides、课时与展品、文本编辑器（Markdown + 学习点）、理解题、推荐阅读、试看。
3. **文本课件**：上传 DOCX 后转换为真实 HTML（`mammoth`），并生成文本学习点；只写本次提交字段，避免并发保存互相覆盖。
4. **媒体**：S3 私有桶存储（`@aws-sdk/client-s3`），媒体流式读取，上传进度与单文件上限提示，视频分块上传（大文件）。
5. **导入**：兼容新版双语 Excel 模板与旧版 Course ID 模板（含「Course ID/课程 ID」联合表头），Course ID 冲突规则，ZIP 安全教育包校验，原始素材异步导入作业（避免网关超时）与作业条件认领。
6. **导出**：导出当前草稿与历史版本课程包；列表行可直接导出。
7. **试看**：按学习语言分别设置视频截止点与文本截止学习点；截止点未填齐时保存被阻止；视频更换后要求重新确认。
8. **价格与 Stripe**：套餐保存后自动创建/更新 Stripe Product + Price；失败只记录 `syncError` 不阻断保存；列表显示同步状态与「重试」。
9. **草稿 / 发布 / 版本**：草稿与正式版本分离，发布、去发布、恢复历史版本；发布、删除草稿、恢复按课程串行化；Approve / Go Live 原子且幂等。
10. **运营位**：热门课程（Top 25 顺序）与 Discovery Banner（双语）。
11. **学员预览**：BackOffice 内自建 Portal 风格预览页（签名短时效 token），可播放媒体，不再跳转 Portal 造成 404。
12. **门户投影**：Portal 课程投影接口（`docs/Portal_Projection_API.md`）。
13. **课程分类**：新增 Chinese Humanities / European Humanities 顶级分类（迁移内置，幂等）。
14. **完整性检查**：发布前课程完整性校验（封面、课时、展品、试看、价格等）。

#### 2.1.2 学生与学习访问

1. **Student Management**：学生列表（状态、订阅、特殊状态筛选）、详情抽屉，支持 `?student=<id>` 直接分享。

1. **工单**：卡片看板、工单详情与学员时间线、附件、工单号按天递增、学员评分展示。
2. **FAQ**：双语 FAQ 卡（Markdown 预览）、分类、问法、问题树编辑与预览、FAQ 发布版本与回滚、变更日志与历史。

4. **数据飞轮**：夜间缺口挖掘、候选队列、运行记录与「立即运行」、助手留存任务、指标看板与趋势图。

## 3. 测试重点

1. **课程 CRUD**：新建（要求中英双语配置）→ 编辑信息 → 添加课时/展品/文本/理解题 → 保存并刷新无丢失。
2. **导入**：用新版双语模板与旧版 Course ID 模板各导入一次；含大量视频的 ZIP 包走分块上传与异步导入，确认进度、失败重试与错误提示。
3. **导出**：分别导出草稿与历史版本，校验 `manifest.json`、媒体与校验和。
4. **试看**：多语言分别设置视频/文本截止点；故意留空确认不能保存；更换视频后确认进入「需重新确认」。

9. **学生**：列表筛选、分页、详情抽屉、`?student=<id>` 直接打开；Portal 未接通时给出明确提示而不是白屏。

11. **AI Tutor**：流式回答、引用脚注、断线续聊、撤销/重试；与 Portal 渲染一致。
12. **Knowledge**：上传图片插入 Widget，非法类型/超大图片被拒。
13. **平台**：发布新构建后打开中的页面能感知版本（有未保存编辑时延后）；多实例下限流一致；`/api/health`、`/api/version` 正常。

### 4.2 环境变量

本次**新增**的变量与必填建议：

| 变量 | 必填 | 说明 |
|---|---|---|
| `STRIPE_SECRET_KEY` | 使用课程价格同步时是 | Sandbox 用 `sk_test_…`；留空时套餐仍可保存，但 Stripe 列显示「未配置」且重试无效 |
| `STRIPE_WEBHOOK_SECRET` | 可选 | 只在接入 Stripe Webhook 回调时需要 |
| `PORTAL_PREVIEW_SECRET` | 部署环境是 | 课程预览 token 签名；留空时本地用开发密钥，部署环境必须显式配置 |
| `PUBLIC_SITE_URL` | 建议 | Portal 站点地址（环境信息展示） |
| `COURSE_MEDIA_BUCKET` / `COURSE_MEDIA_PREFIX` | 部署环境是 | 课程媒体与 Knowledge 图片的私有 S3 桶；未配置时回退本地磁盘，课程包导入/导出会返回 `PACKAGE_STORAGE_UNAVAILABLE` |
| `COURSE_PACKAGE_BUCKET` / `COURSE_PACKAGE_PREFIX` | 可选 | 留空复用媒体桶；默认 prefix `staging/` |
| `S3_ENDPOINT` / `S3_FORCE_PATH_STYLE` | 可选 | 仅 S3 兼容存储（MinIO）时需要 |
| `PORTAL_HELPDESK_BASE_URL` / `PORTAL_HELPDESK_TOKEN` | 使用 HelpDesk/学生时是 | Portal 工单与学生数据源；未配置时工单接口返回 503 `HELPDESK_NOT_CONNECTED` |
| `ADMIN_HELPDESK_TOKEN` | 使用 Portal → Admin 入站接口时是 | 与 Portal 的 `ADMIN_HELPDESK_TOKEN` 相同 |
| `PORTAL_STUDENTS_BASE_URL` / `PORTAL_STUDENTS_TOKEN` | 可选 | 学生模块专用；留空复用 `PORTAL_HELPDESK_*` |
| `OPENROUTER_API_KEY` | 使用 HelpDesk AI / AI Tutor 时是 | HelpDesk 分级方案的唯一必填项 |
| `KS_BASE_URL` / `KS_SERVICE_TOKEN` | 拆分部署时是 | agent 独立部署时调 KS；单服务留空即可 |

已有变量继续沿用：`APP_ENV`（SIT）、`NODE_ENV`、`DATABASE_URL`、`BACKOFFICE_APP_URL`、`AUTH_TOKEN`、`SESSION_SECRET`、`APP_ROLES`、`AWS_REGION` 等。

HelpDesk 分级方案（`HELPDESK_SUGGEST_*`、`HELPDESK_EMBED_MODEL`、`HELPDESK_RERANK_*`、`HELPDESK_SEARCH_SCOPE`、`HELPDESK_QUERY_CONTEXT`、`HELPDESK_MODEL_HEALTH_ALERT` 等）**都有代码缺省值**，部署侧无需配置；需要临时调整时按 `server/.env.example` 注释设置，均为运行时读取、不必重启。

### 4.3 数据初始化（按需）

- **HelpDesk FAQ 数据不会在 SIT 自动灌入**：自动灌演示数据只在 `APP_ENV=DEV` 且 `NODE_ENV=production` 时触发，SIT/UAT/PROD 永远不灌。
- 需要在 SIT 预置 FAQ 时，使用正常服务层导入（按 key 幂等，可重复执行）：

```bash
cd server
DATABASE_URL=… npm run seed:helpdesk-faqs -- eval/helpdesk/faq-library.json
```

- 如需向量检索，配置 `HELPDESK_EMBED_MODEL` 后新建/发布版本会自动计算；历史版本可用 `npm run helpdesk:faq-vectors -- --release live` 补算。
- 课程/学生数据从 Portal 与导入包获得，本次无内置业务数据。

### 4.4 发布步骤

1. 确认 Node.js ≥ 22.19、npm ≥ 10（`server` 的 `pi-agent-core` 要求）。
2. `server` 与 `client` 分别 `npm ci`、构建；确认 `client/dist` 与 `server/dist` 存在。
3. 备份 SIT 数据库，执行 `npx prisma migrate deploy`，确认 17 个迁移全部成功。
4. 按 4.2 配置环境变量（尤其 `STRIPE_SECRET_KEY`、`PORTAL_PREVIEW_SECRET`、`COURSE_MEDIA_BUCKET`、Portal 集成令牌、`OPENROUTER_API_KEY`）。
5. 启动服务；`APP_ROLES` 留空时为单服务全角色。
6. 检查 `/api/health` 返回 200、`/api/version` 返回当前构建版本。
7. 按第 3 节完成冒烟后再通知测试。

### 4.5 发布后冒烟

## 6. 已知问题与限制

| 级别 | 类型 | 问题 | 影响与处理 |
|---|---|---|---|
| 高 | 部署 | 未配置 `STRIPE_SECRET_KEY` | 套餐可保存但 Stripe 同步恒失败（NOT_CONFIGURED）；配置后需重启并逐个「重试」 |
| 高 | 部署 | 未配置 `COURSE_MEDIA_BUCKET` | 部署环境媒体落本地磁盘；课程包导入/导出返回 `PACKAGE_STORAGE_UNAVAILABLE` |
| 高 | 部署 | 未配置 Portal 集成令牌 | HelpDesk 工单/学生列表不可用并提示未接通；不阻塞课程模块 |
| 中 | 限制 | 试看「计费」只支持 1/3/6/12 个月 | 其他周期需先扩展前端选项；历史导入的非常规周期会原样显示 |
| 中 | 限制 | Stripe lookup key 同一账户内唯一 | 同周期套餐会被拒绝保存；这是设计约束，避免 Price 冲突 |
| 中 | 限制 | 视频/3D 缩略图需运营提供 | 缺缩略图时导入 warning、发布阻断；P1 不引入 ffmpeg 抽帧 |
| 中 | 限制 | 大气包导入依赖异步作业 | 需要 worker 进程存活；作业 10 分钟无心跳会被回收重试（最多 3 次） |
| 低 | 限制 | 登录/邮件限流已改为数据库计数 | 需要 `backoffice_rate_limits` 迁移成功 |
| 低 | 限制 | 客户端浏览器 E2E 仅本地运行 | CI 只跑单元/组件测试，浏览器 E2E 需手动 `npm run test:e2e:*` |
| 低 | 限制 | HelpDesk 分级方案依赖 OpenRouter | 无 key 时回退代码逻辑/字词检索，AI 建议不可用 |
| 低 | 限制 | 无 CSRF token，依赖 SameSite=Lax | 跨站写请求受 Cookie 策略阻断；如需强防护后续再加 |
| 信息 | 范围 | 部分 HelpDesk 员工页面无 Figma 稿 | 复用现有 HelpDesk 样式，需视觉验收 |
